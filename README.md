# Вебсайт «Економічна безпека КНР»

Файли: index.html (про автора), china.html (аналіз і графіки), risks.html (загрози та перспективи), style.css (оформлення).

## Публікація на GitHub Pages
1. Створіть новий публічний репозиторій на GitHub.
2. Завантажте всі чотири файли в корінь репозиторію.
3. Відкрийте Settings → Pages.
4. У розділі Build and deployment оберіть Deploy from a branch, гілку main і папку /(root), натисніть Save.
5. Після публікації GitHub покаже адресу сайту.

Перед публікацією замініть заглушки в index.html та підпис автора у футерах. Графіки використовують Chart.js із CDN, тому для них потрібне підключення до інтернету.

Аналітичні висновки перенесені з наданого документа. Числові ряди на графіках — із наданого Excel-файлу. Періоди для кожного показника різняться; відсутні дані не домислювалися.
